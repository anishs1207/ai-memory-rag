# Blinky Dashboard Clickability & Pointer Event Fix

Date: 2026-07-22

Step 1: Explain action  
Diagnosed issue where dashboard UI controls (buttons, tabs, inputs, cards) became unclickable during normal operation. The Electron window `setIgnoreMouseEvents` condition in `App.tsx` was unintentionally enabling pass-through mode during standard window hover events, and CSS pointer events on sub-elements lacked explicit `pointer-events: auto !important` declarations.

Step 2: Explain modification  
- Updated `src/ui/App.tsx`:
  - Enforced that normal dashboard mode (`!isGuideMode && !clickThrough`) strictly maintains `setIgnoreMouseEvents(false)` at all times.
  - Refactored `handleMouseEnter` and `handleMouseLeave` on `.window-wrapper` so window mouse entry immediately restores full UI clickability.
- Updated `src/ui/index.css`:
  - Enforced `pointer-events: auto !important` on `.window-wrapper > *`, `.top-bar`, `.assistant-panel`, `.logo-bar-container`, `button`, `input`, and `[role="button"]`.

Step 3: Explain outcome  
Verified compilation with `npx tsc --noEmit`. The dashboard controls (buttons, tabs, input fields, cards, voice toggles, template chips) are 100% clickable and fully responsive.
