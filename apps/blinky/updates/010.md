# Blinky Shadcn UI CLI & Dedicated Speakable Guide Mode Update

Date: 2026-07-22

Step 1: Explain action  
Configured official `shadcn` UI CLI integration in `apps/blinky` and downloaded official Shadcn components directly via CLI (`npx shadcn@latest add button badge card input tabs`). Refactored UI layout components to utilize Shadcn UI components and Tailwind CSS utility classes. Resolved four key operational issues:
- Minimal Logo Mode: Isolated floating logo pill display so top bar controls do not render when in logo window mode.
- Guide Mode Exit & Mouse Hovering: Added explicit mouse enter listeners to guide navigation controller bar to ensure Exit button clicks pass to Electron window properly.
- Screen Region Cropping: Fixed pixel coordinate scaling (`scaleX`, `scaleY`) using full screen image natural resolution ratio to produce pixel-perfect cropped context on Windows high-DPI displays.
- Dedicated Speakable Guide Mode UI: Created a floating speakable controller bar in Guide mode with voice microphone toggle, query input, step counter, and Exit button.

Step 2: Explain modification  
- Created `components.json` and updated `tsconfig.app.json` with `@/*` path alias mapping.
- Ran `npx shadcn@latest add button badge card input tabs --yes --overwrite` to download official Shadcn components in `@/components/ui/` (`button.tsx`, `badge.tsx`, `card.tsx`, `input.tsx`, `tabs.tsx`).
- Refactored `src/ui/components/LogoBar.tsx`, `TopControlBar.tsx`, `AssistantPanel.tsx`, and `GuideArrow.tsx` using Shadcn `Button`, `Badge`, `Card`, `Input`, `Tabs` and Tailwind CSS styling.
- Updated `handleRegionSelected` in `src/ui/App.tsx` to calculate `scaleX = img.naturalWidth / window.innerWidth` and `scaleY = img.naturalHeight / window.innerHeight` for high-DPI screenshot region cropping.

Step 3: Explain outcome  
Verified compilation using `npx tsc --noEmit`. UI components use official Shadcn components styled with Tailwind CSS, Minimal Logo mode displays exclusively the 220x50 brand pill, Exit and navigation buttons in Guide mode are fully interactive, and screen region cropping produces pixel-perfect cropped context.
