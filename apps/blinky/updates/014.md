# Blinky Electron Window App-Region Drag Fix

Date: 2026-07-22

Step 1: Explain action  
Diagnosed root cause for unclickable controls while window was movable:
`-webkit-app-region: drag` set on `.top-bar` was inherited by all child buttons, inputs, tabs, and icons. In Electron, any element marked as draggable intercepts mouse clicks as window drag actions, preventing React `onClick` event handlers from executing.

Step 2: Explain modification  
- Updated `src/ui/index.css`: Added explicit `-webkit-app-region: no-drag !important` to `button`, `input`, `select`, `textarea`, `label`, `a`, `[role="button"]`, `.no-drag`, `.control-icon-btn`, `.top-bar-btn`, `.nav-tab-btn`, `.nav-tabs`, `.color-option-dot`, and `.assistant-panel`.
- Updated `src/ui/components/ui/button.tsx`: Passed `style={{ WebkitAppRegion: "no-drag", ...props.style }}` to all Shadcn `Button` elements.
- Updated `src/ui/components/ui/input.tsx`: Passed `style={{ WebkitAppRegion: "no-drag", ...props.style }}` to all Shadcn `Input` elements.

Step 3: Explain outcome  
Verified compilation using `npx tsc --noEmit`. Dragging operates smoothly when mouse dragging top bar whitespace, while all buttons, inputs, tab switches, color pickers, and dashboard controls execute click actions seamlessly.
