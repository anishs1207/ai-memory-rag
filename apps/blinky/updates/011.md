# Blinky Vite Path Alias Module Resolution Fix

Date: 2026-07-22

Step 1: Explain action  
Diagnosed module resolution error reported by Vite during `npm run dev`:
`Error: The following dependencies are imported but could not be resolved: @/lib/utils`.
Vite was unable to resolve `@/lib/utils` because `vite.config.ts` lacked path alias resolution for `@` pointing to `./src/ui`.

Step 2: Explain modification  
- Updated `vite.config.ts`:
  - Imported `path` module.
  - Added `resolve.alias` configuration mapping `@` to `path.resolve(__dirname, './src/ui')`.
- Updated Shadcn UI component files (`button.tsx`, `badge.tsx`, `input.tsx`, `card.tsx`, `tabs.tsx`) to consistently use `@/lib/utils` path alias.

Step 3: Explain outcome  
Verified resolution using `npx tsc --noEmit` and `npx vite build`. Vite dev server and production builder resolve `@/lib/utils` and all `@/*` Shadcn UI module imports cleanly.
