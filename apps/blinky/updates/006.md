# Update 006 - Local Chat Persistence & Full Transparency Minimal Logo Mode

Date: 2026-07-21

Step 1: Implemented native IPC handlers in `main.ts` (`save-chat-history`, `load-chat-history`, `clear-chat-history`) to persist chat JSON data and captured screenshot PNG files inside `userData/history/`.
Step 2: Created `LogoBar.tsx` component and updated `TopControlBar.tsx` to support 100% full background transparency (opacity 0.0) and a Minimal Logo Mode (`'logo'`) layout that collapses the app window down to a floating `220x50` brand pill.
Step 3: Added a local history memory drawer in `AssistantPanel.tsx` and connected `App.tsx` state to auto-load past sessions and log queries, responses, voice flags, and screen captures on every interaction.

## Purpose
This update fulfills all requirements in `new-features/1.md` by giving users full control over transparency, enabling an ultra-compact floating logo bar layout, and ensuring all past chat conversations and captured context screenshots are safely saved locally on disk across application restarts.

## Journey
When implementing screenshot persistence, sending raw base64 data URLs directly in large JSON files can lead to performance degradation. To solve this efficiently, we separated JSON metadata from heavy image binary payloads by extracting base64 data, writing standalone PNG assets to a `captures` subdirectory on disk, and referencing relative image filenames in the saved JSON index.
