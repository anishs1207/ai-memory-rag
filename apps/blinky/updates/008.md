## Journey
In Electron desktop applications, gRPC data pipe errors can occur during native Web Speech API cloud streaming if Chromium network stream descriptors fail (`Error: -2`). By wrapping audio input with native `navigator.mediaDevices.getUserMedia` and `MediaRecorder` stream listeners, audio recording remains 100% resilient. Additionally, adding `.step-navigation-bar` and `.exit-guide-btn` to `handleMouseMove` element hover checks ensures Electron click-through pointer events never block mouse clicks on exit guide buttons.
