# Update 004 - Fixing ESM Import Errors

Date: 2026-05-12

Step 1: Identified a `ReferenceError: require is not defined` in the main process.
Step 2: Replaced the CommonJS-style `require('electron')` with a proper ESM `import` for the `screen` module.
Step 3: Verified that the imports are now consistent with the project's `"type": "module"` configuration.

## Purpose
This fix ensures that the Electron main process can correctly access system screen information for window centering without crashing on startup.

## Journey
I accidentally introduced a `require` call in a project that is strictly ESM. This is a common pitfall when working with Electron in ESM mode. By moving `screen` to the main `import` list, I resolved the crash and restored the stealth toolbar's functionality.
