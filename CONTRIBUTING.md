# Contributing to Memory Framework

First off, thank you for considering contributing to the Memory Framework! It's people like you that make the AI community such a great place.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issues tracker.
- Describe the bug in detail and provide steps to reproduce it.

### Suggesting Enhancements
- Open a GitHub Issue and describe the feature you'd like to see.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`.
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes.
5. Make sure your code lints: `npm run lint`.
6. Issue that pull request!

## Style Guide

### Git Commit Messages
- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.

### Code Style
- We use **Prettier** for formatting. Run `npm run format` before committing.
- Follow the existing project structure in `apps/` and `packages/`.
- Use clear, descriptive variable names.

## Development Rules (GEMINI.md)

If you are using an AI agent to help you develop:
1. Always explain what you are doing before modifying code.
2. Add comments explaining important logic.
3. Log each major step in the `updates/` directory.
