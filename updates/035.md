## Journey and Troubleshooting

### 1. Handling strict check-types array index warnings
- **Problem**: The initial compile check failed due to index lookup warnings (e.g. `action.payload[0].id` and `conversations[0].id`) as TypeScript strict settings consider index lookups potentially undefined.
- **Analysis**: Since Next.js and TypeScript check in strict mode, accessing index 0 in an array is marked as `possibly undefined` even when checking the length beforehand.
- **Solution**: Refactored the lookups to use optional chaining and fallback values: `action.payload[0]?.id || ""` and `conversations[0]?.id === id`.
- **Result**: Type checks compiled successfully with no remaining errors.
